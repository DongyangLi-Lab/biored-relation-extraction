# INLS 613 · BioRED 实验设计

项目目标是从生物医学文本中识别两个已知实体之间表达的关系。Baseline 和强模型两条线并行推进，每条线都回答两个问题。

| 问题 | 样本 | 模型输出 | 主要指标 |
|---|---|---|---|
| **Q1：有没有关系？** | 同一摘要内的候选实体对 | 有 BioRED 关系标注 / 无 BioRED 关系标注 | 有关系类别的 F1 |
| **Q2：是哪种关系？** | BioRED 已标注关系的实体对 | 八种关系类型中的一种 | 八类 macro-F1 |

Q1 是主任务。Q2 直接使用标注为有关系的实体对作为输入，因此它衡量的是已知有关系时的分类能力。Baseline 线用结构与结构加文本的对照衡量文本的额外价值。两条线用相同的文本输入比较传统模型与预训练模型。

## 数据和共享接口

使用原始 BioRED BioC JSON 和官方训练、验证、测试划分，按现有候选规则构建摘要级实体对。已标注的实体 ID 同时用于合并同一摘要内的重复提及。有无同句提及是结构特征和结果分组依据。

| 样本核对 | 训练 | 验证 | 测试 |
|---|---:|---:|---:|
| 摘要 | 400 | 100 | 100 |
| Q1 候选实体对 | 21,755 | 6,334 | 7,047 |
| Q1 有标注关系，也是 Q2 样本 | 4,174 | 1,161 | 1,163 |
| Q1 无标注关系 | 17,581 | 5,173 | 5,884 |

- 数据来源和下载步骤见 [data/README.md](../data/README.md)。原始 BioC JSON 下载到 `data/raw/BioRED/`，候选表与关系标签表在 `data/`。
- 用 `split + pmid + pair_type + 排序后的两个实体 ID` 合并。同一个实体对的顺序在两个来源里可能相反。实体 ID 按字符串读入。
- 共享表每行是一对实体，包含上述定位字段、`annotated_relation`、`relation_type`、结构特征与遮蔽后的上下文。未标注样本的 `relation_type` 留空。
- 结构特征首轮用最近词距、各自的提及次数、是否共享句子及实体对类型。文本取距离最近的一组目标提及所在句子，按原文顺序拼接并去重，用 `ENTITY1` 和 `ENTITY2` 替换相应目标提及。两条线读取同一列文本，分别使用各自的文本表示。

## 两条模型线

| 模型线 | Q1 有没有关系 | Q2 是哪种关系 |
|---|---|---|
| **Baseline** | 同句规则，逻辑回归跑三组输入，线性 SVM 和多项朴素贝叶斯跑仅文本 | 多数类，多项逻辑回归跑三组输入，多项朴素贝叶斯跑仅文本 |
| **强模型** | 从 BioBERT 基础预训练权重出发，在候选实体对上微调二分类模型 | 从同一基础预训练权重出发，在已标注实体对上微调一个八分类模型 |

Baseline 用 Python 和 scikit-learn，文本用 TF-IDF 词和短语。模型和特征配置见 [Baseline 开工指南](../baseline/README.md)。强模型首选 proposal 已提到的 BioBERT，先用小批训练样本跑通数据读取、实体标记和训练，确认算力后再跑全量。报告中称 BioBERT 为预训练模型对照。开工前两条线用同一批样本核对输入和标签。 [BioBERT 原论文](https://pubmed.ncbi.nlm.nih.gov/31501885/)

## 共用评估

- **Q1** 报告有关系类别的 F1、精确率、召回率和 average precision。用逻辑回归「结构加文本」减去「仅结构」的 F1 回答文本增益问题，用 BioBERT 和「仅文本」逻辑回归比较同一文本输入下的模型表现。按是否同句分组时同时报告样本数。
- **Q2** 报告八类 macro-F1、各类 F1、测试样本数和混淆矩阵，重点看正负相关之间的误判，以及它们和 Association 的混淆。Drug Interaction 和 Conversion 在验证集中没有样本，测试集分别有 2 条和 1 条，用具体预测辅助解释。
- 两条线使用同一套训练、验证和测试样本。模型、TF-IDF 和需要拟合的预处理使用训练集。模型选择和 Q1 阈值使用验证集，方案固定后再跑测试。两条线都按共享样本键交付预测标签，Q1 同时交付有关系的分数，便于生成统一的两张结果表和逐例对照。

## 两人并行，一人主导

| 分工 | 可以立即开始 | 合并后的交付 |
|---|---|---|
| **项目主导负责强模型** | 确定共享数据接口和评估口径，准备带实体标记的共享文本，用小批训练样本跑通 BioBERT | 两项任务的 BioBERT 结果和方法，统筹模型比较和报告结论 |
| **Baseline 负责人** | 用现有候选表和标签表搭建规则参照和逻辑回归，先完成结构特征及仅结构模型 | 接入共享文本，完成两项任务的 Baseline、结果表和相应报告内容 |

第一次交接只需要一小份按共享样本键对齐的样本，核对标签、实体位置和上下文。全量文本准备期间，Baseline 线可以先跑结构模型和规则参照，强模型线可以调通训练流程。两条线在验证集跑通 Q1 后，复用同一套数据接口完成 Q2，再共同核对测试结果和报告。
